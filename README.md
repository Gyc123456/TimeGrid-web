# TimeGrid

基于 Vue 3、TypeScript、Element Plus、Vite 的可拖拽甘特图。每个项目是一级分组，每位参与成员独占一行。

## 启动

```sh
npm install
npm run dev
```

## 构建

```sh
npm run build
npm run preview
```

## 使用

- 点击「新建项目」设置项目名称、开始日期、结束日期及颜色；项目起止日期独立保存。添加成员时默认使用项目日期。
- 点击项目右侧加号或「添加成员」添加参与人。
- 在左侧直接编辑成员的开始、结束日期，结束日期不能早于开始日期。
- 拖动时间条整体移动排期，拖动左右两端分别调整开始、结束日期，按天吸附；起止日期均计入工期。
- 点击项目标题折叠成员，通过月份选择器、左右箭头切换月份，通过右侧下拉框调整日期列宽。
- 右键人员时间条或人员行打开 Element Plus 详情弹窗（也支持双击时间条或聚焦后按 Enter）。姓名只读；修改日期自动计算工作时长，修改时长保留开始日期并更新结束日期。
- 详情可填写备注、选择多个附件、下载或移除附件；点击「保存详情」才提交，取消会丢弃草稿。附件保存在浏览器本地，单个不超过 1 MB，每位成员合计不超过 2 MB；存储空间不足时会提示并保留弹窗。JSON 导出包含附件内容。
- 搜索支持项目名称、成员姓名和角色；时间轴支持横向滚动，左侧成员信息保持固定。
- 数据自动保存在当前浏览器的 localStorage，可导出 JSON 备份。尚未接入后端，数据不会跨设备同步。

## 代码结构

```text
src/
  App.vue                    # 应用入口：语言与全局 UI 配置
  main.ts                    # 创建应用、加载样式
  layout/index.vue           # 提供页面状态，组装页面及弹窗
  components/
    layout/                  # 侧栏、顶部导航、标题、统计、页脚
    projects/                # 项目编辑、图标选择、右键菜单
    schedule/                # 甘特图、工具栏、排期详情
    attachments/             # 附件预览
  composables/               # 共享状态、项目编辑、详情、拖拽、动画、附件生命周期
  types/project.ts           # 项目、成员、附件类型
  config/projectAppearance.ts # 图标库、调色盘、外观映射
  data/seedProjects.ts        # 示例数据
  utils/schedule.ts          # 日期、冲突、完成状态等纯函数
  styles/                    # 基础、布局、甘特图、表单、响应式样式
```

`layout/index.vue` 创建一次 `useTimeGrid` 并通过有类型的 `provide/inject` 向业务组件共享状态。组件使用 `useTimeGridContext`，不各自创建数据副本；纯计算放在 `utils`，交互副作用放在对应的 composable，并在卸载时清理事件、计时器和动画。

## 代码规范

建议使用 Node.js 24 LTS（测试直接运行 TypeScript 工具函数）。ESLint 10 检查 Vue 3 和 TypeScript，Prettier 统一模板、脚本、样式及配置文件的格式；使用两空格缩进、单引号和多行属性。

```sh
npm run format        # 全项目格式化
npm run format:check  # 只检查格式
npm run lint          # ESLint 检查，警告也会使检查失败
npm run lint:fix      # 自动修复可修复的问题
npm run typecheck     # Vue + TypeScript 类型检查
npm run check         # ESLint、格式、测试、类型检查与生产构建
```

提交前运行 `npm run check`。新增页面组件应按业务放在相应子目录，避免继续向入口文件堆积逻辑。

首次运行显示当前月份的示例项目。默认时间单位是天，同名成员在人数统计中视为同一人。

## 组件与测试

通用交互组件使用 Element Plus，并通过 ConfigProvider 配置简体中文；甘特时间轴保留自定义拖拽实现。主题变量位于 `src/styles/`。

```sh
npm test
```

日期单元测试覆盖首尾日期、跨月跨年、闰年和无效输入；运行测试需要支持 TypeScript 类型擦除的 Node.js（本项目验证使用 Node 24）。

## 人员视图、冲突规则与动效

- 点击侧栏「项目排期」或工具栏「全部项目」清除搜索、项目和人员筛选，并展开全部项目。
- 「按人员」按姓名归组，每个参与项目在独立行展示；同名人员（忽略首尾空格）按同一人员检查。可使用人员筛选查看某位成员。
- 默认使用「冲突警告」：拖动、拉伸、编辑日期或新增排期时，如与同一人的其他排期重叠，会提示且允许修改。重叠双方以黄色边框和轻微黄光标记；包含首尾日期，因此同一天也算重叠。
- 「禁止重叠」：拖动和拉伸过程中实时检测重叠，冲突双方闪烁轻微红光，移出冲突范围后恢复；鼠标松开时检查最终排期，发生冲突才提示并恢复拖动前的起止日期；表单和详情中的冲突修改不会提交。切换规则不会删除已有冲突，已有冲突继续标记，可通过修改日期消除。检查始终覆盖全部项目，不受搜索、月份或视图筛选影响。
- 时间轴工具栏的「查看开始日期」「查看结束日期」支持跨月、跨年范围，项目视图和人员视图共用这一范围。切换视图、返回全部项目会保留范围；月份选择、前后月和「今天」按钮会重置到对应整月。日期列在范围首日及每月首日显示月份，单次查看最多 3660 天。
- 重叠规则自动保存在当前浏览器。拖拽结束才保存排期；指针取消或窗口失焦会恢复拖动前的日期。
- GSAP 提供时间条入场、视图切换和冲突黄光动画；开启系统「减少动态效果」时保留静态冲突标记，不播放闪烁。
- 点击附件名打开预览：支持图片、PDF、纯文本及浏览器支持的音视频。HTML 作为文本显示；其他格式提示下载后查看。预览在本地进行，不发送到第三方服务。
